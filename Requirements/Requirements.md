# Requirements

## Website

1. There will be an accessible website to contain the project.
2. The website will allow users to register with an email and password.
3. The website will allow registered users to log in.

## Primary Functionality

Once logged in:
1. Users will be able to log back out.
2. Users will be able to navigate between:
   1. Subjects (initally just maths);
   2. 
   2. Level (initially just National 5);
   3. Topic
3. Users will be able to view 'lessons' for the chosen topic.
4. Users will be able to generate suitable past paper-like questions for the topic based on randomised inputs and computed correct answer.
5. Users will be able to choose a selection of topics and answer random questions thereof.
6. Users will be able to view a summary of their scores across different topics to assess strengths.

## Backend Functionality

1. The system will have an attached database to store:
   1. Login information;
   2. Scores for different topics
2. The system will require a system of rendering latex for mathematical notation.
